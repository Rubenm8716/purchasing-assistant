# Purchasing Assistant

Internal purchasing policy and receipt management
application for company employees.

## Tech Stack

- Frontend: Next.js, React, TypeScript
- Backend: Python, FastAPI
- Database: PostgreSQL
- AI: OpenAI API
- Cloud: AWS
- Development: Docker, GitHub

## Features (Planned)

- Employee authentication
- AI purchasing assistant
- Company purchasing policy validation
- Manager approval requests
- Receipt uploads
- Administrative dashboard
- Purchase and audit history
